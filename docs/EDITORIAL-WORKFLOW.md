# Editorial workflow

## Contributor

1. Create an adult contributor account.
2. Open **Write a story**.
3. Save a draft as many times as needed.
4. Submit the story for review.
5. Read editorial feedback.
6. Revise and resubmit when changes are requested.

## Editor

1. Open **Review queue**.
2. Begin review on a submitted story.
3. Read the story and revision history.
4. Record one decision:
   - Request changes
   - Approve
   - Reject
5. Publish an approved story immediately or schedule it.

## Administrator

The administrator can perform all editor actions and can also:

- create or delete empty categories
- change account roles
- suspend or reactivate accounts
- delete stories when necessary

## Recommended publication policy

Maintain written rules for originality, cultural sensitivity, child dignity, factual notes, copyrighted media, artificial-intelligence assistance, and appeals. Keep sensitive identifying information out of fictional stories inspired by real children.
